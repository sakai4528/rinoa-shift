# カラオケサロン リノア シフト表・タイムカード（LINEミニアプリ版）

スタッフは LINE のリッチメニューから開き、**出勤・退勤の打刻／希望休の提出／確定シフトの確認**をします。
経営者は同じアプリの管理画面で、**1か月の月カレンダー上で出勤・休を割り当て、公開（全員にLINE通知）、勤怠の集計・修正**をします。

```
index.html      スタッフ・経営者が開く画面（LIFF）。GitHub Pages などの https で公開する
gas/Code.gs         保存と通知（Google Apps Script）。スプレッドシートに保存、Messaging API で通知
gas/appsscript.json Apps Script の設定（タイムゾーン Asia/Tokyo）
```

---

## セットアップ手順（所要 40〜60分）

### 1. Apps Script（保存・通知）を作る

> 保存先のスプレッドシート「リノア シフト表データ」は作成済みです（Googleドライブ）。その「手順」シートにも同じ手順を書いてあります。

1. スプレッドシート「リノア シフト表データ」を開き、メニュー「拡張機能」→「Apps Script」（スプレッドシートに紐づくスクリプトになるので、保存先の指定は不要です）。
2. `コード.gs` の中身を全部消し、`gas/Code.gs` の内容を貼り付けて保存。
3. 左の歯車「プロジェクトの設定」→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック → エディタに出た `appsscript.json` を `gas/appsscript.json` の内容で置き換えて保存。
4. 同じ「プロジェクトの設定」の下、「スクリプト プロパティ」に次を追加（値は手順2・3で取れたら後から入れてもよい）。

   | プロパティ | 値 |
   |---|---|
   | `MESSAGING_TOKEN` | リノア公式アカウントの Messaging API チャネルの「チャネルアクセストークン（長期）」 |
   | `LIFF_CHANNEL_ID` | 手順2で作る LINEログインチャネルの「チャネルID」 |
   | `LIFF_URL` | 手順2で出来る LIFF URL（`https://liff.line.me/…`）。通知文に載せるリンク |

5. エディタ上部の関数選択で `setup` を選び ▶ 実行。初回は権限の許可画面が出るので許可する（「安全ではないページ」と出たら「詳細」→「（プロジェクト名）に移動」）。実行すると「リノア シフト表データ」というスプレッドシートが Google ドライブに作られ、シートが用意されます。
6. 続けて `setupTriggers` を選び ▶ 実行。毎朝 9:05 に「締切前の未提出者への催促」「退勤忘れの連絡」が自動で送られます。
7. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 説明：任意　／　次のユーザーとして実行：**自分**　／　アクセスできるユーザー：**全員**
   - 「デプロイ」→ 表示された **ウェブアプリの URL（…/exec）** を控える。

> コードを直したときは「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ。URL は変わりません。

### 2. LINE Developers で LIFF アプリを作る

1. [developers.line.biz](https://developers.line.biz/console/) にログイン → リノア公式アカウントがある**プロバイダー**を開く。
2. 「チャネル作成」→「**LINEログイン**」。名前「リノア シフト表」、アプリタイプ「ウェブアプリ」。作成後、チャネル基本設定の**チャネルID**を控える（→ `LIFF_CHANNEL_ID`）。
3. そのチャネルの「LIFF」タブ →「追加」。
   - LIFFアプリ名：リノア シフト表　／　サイズ：**Full**
   - エンドポイントURL：手順3で公開する画面の URL（先に仮で `https://example.com` を入れ、後で直してよい）
   - Scope：**profile** と **openid** にチェック　／　ボットリンク機能：**On (Aggressive)**（友だち追加を促す）
   - 追加すると **LIFF ID**（`2001234567-AbCdEfGh` の形）と **LIFF URL** が出る。両方控える。
4. チャネルを「公開」にする（開発中のままだとチャネル管理者以外が開けません）。
5. 「Messaging API」側（公式アカウントのチャネル）→「Messaging API設定」の一番下で**チャネルアクセストークン（長期）**を発行して控える（→ `MESSAGING_TOKEN`）。同じ画面の「応答メッセージ」はオフ推奨。

### 3. 画面（index.html）を公開する

1. `index.html` の先頭近くの `CONFIG` を書き換える。

   ```js
   const CONFIG = {
     liffId: "2001234567-AbCdEfGh",                       // 手順2-3 の LIFF ID
     apiUrl: "https://script.google.com/macros/s/…/exec"  // 手順1-7 の URL
   };
   ```

2. https で公開する。いちばん簡単なのは GitHub Pages：
   - GitHub にリポジトリ（例 `rinoa-shift`）を作り、`index.html` を置く。
   - Settings → Pages → Branch を `main`、フォルダを `/ (root)`→ Save。
   - 数分で `https://ユーザー名.github.io/rinoa-shift/` で開けるようになる。
3. 手順2-3 の LIFF の**エンドポイントURL**を、この公開 URL に直す。

### 4. 公式アカウントのリッチメニューにつなぐ

[LINE Official Account Manager](https://manager.line.biz/) → リッチメニュー → ボタンのアクションを「リンク」にして **LIFF URL**（`https://liff.line.me/…`）を入れる。
「シフト表・タイムカード」の1ボタンで足ります（アプリ内でタブを切り替えます）。

### 5. 最初の動作確認

1. 自分の LINE でリッチメニューから開く → 名前を登録 → 下の「経営者用」→ 暗証番号 **1234** → 管理者になる。
2. 「設定」で店名・標準の出勤時間・必要人数・**暗証番号の変更**。
3. Apps Script で `testPush` を実行 → 自分の LINE に「【テスト】…」が届けば通知 OK。
4. スタッフに友だち追加してもらい、各自リッチメニューから開いて**名前を登録**してもらう。これで「スタッフ」タブに自動で並び、通知も届きます。

## 日々の流れ

| いつ | だれ | すること |
|---|---|---|
| 毎月 20日まで（設定で変更可） | スタッフ | 「希望を出す」で翌月の希望休・時間指定を送信。締切3日前と当日の朝9時に未提出者へ自動催促 |
| 締切後 | 経営者 | 「シフト作成」月カレンダーで日をタップ → 出勤／休／時間／同伴出勤／早上がり を設定 →「シフトを公開する」で全員に通知 |
| 毎日 | スタッフ | 出勤したら「出勤」、帰るとき「退勤」。今月の累計労働時間がその場で見える |
| 退勤忘れ | 自動 | 翌朝9時に本人へ連絡。本人が退勤時刻を入れると「手入力」の印が付く |
| 月末 | 経営者 | 「勤怠」で人別の実働合計を確認、必要なら明細を修正、「給与計算用テキスト」をコピー |

### 時間の丸め（タイムカード）
初期設定は **30分刻み・四捨五入**（15分未満は切り捨て、15分以上は30分扱い）。9:14→9:00、9:15→9:30、9:45→10:00。出勤・退勤それぞれに適用し、休憩分を引きます。設定で「15分刻み」「切り捨て」などに変更できます。

### データの保存場所
Google ドライブの「リノア シフト表データ」スプレッドシート。シート `staff`（スタッフ）`shifts`（月ごとのシフト）`wishes`（希望）`timecards`（打刻）`admins`（管理者）`settings`（設定）`log`（操作履歴）。
手で直すことも可能ですが、`cells` `days` 列は JSON なので、できるだけアプリ側で修正してください。

### よくある質問
- **管理者を増やしたい**：その人が自分の LINE で開き、「経営者用」→ 暗証番号を入れると管理者になります。外すときは `admins` シートの行を削除。
- **スタッフが先に経営者側で登録されていて、本人が登録したら2人になった**：どちらかを「編集」→「シフト表に表示する」を外す。シフト履歴を残したい方を残してください。
- **通知が届かない**：`MESSAGING_TOKEN` が入っているか、スタッフが公式アカウントをブロックしていないか、`setup` を実行して権限を許可したかを確認。`testPush` で試せます。
- **「開けませんでした」と出る**：外部ブラウザで開くと LINE ログインが挟まります。LINE アプリ内のリッチメニューから開いてください。
